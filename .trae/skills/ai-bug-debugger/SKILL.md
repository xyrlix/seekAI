# AI 开发调试与错误排查

## 支持的问题类型

### 1. Python 语法错误
- SyntaxError
- IndentationError
- NameError
- TypeError

### 2. 运行时错误
- ValueError
- KeyError
- IndexError
- AttributeError
- FileNotFoundError

### 3. PyTorch 相关错误
- 张量维度不匹配
- 设备不一致（CPU/GPU）
- 梯度计算错误
- 模型加载失败
- CUDA Out of Memory

### 4. 依赖与环境问题
- 模块导入失败
- 版本不兼容
- CUDA 驱动问题

## 排查流程

1. **复现问题**：确认错误发生的条件
2. **定位根因**：分析错误堆栈
3. **给出方案**：提供修复代码和步骤
4. **验证修复**：确保问题已解决
5. **预防措施**：说明如何避免同类问题

# 修复后的代码
```

[如何避免同类问题]

## 使用方式

```
"我遇到了这个报错：[粘贴错误]"
"代码运行结果不对，期望是 A，实际是 B"
"训练时 GPU 内存爆了，怎么解决？"
"模型预测结果全是一样的，怎么回事？"
```
