## 项目结构模板

每个项目应包含：

```
project_name/
├── data/              # 项目数据
├── notebooks/         # 探索性分析
├── src/               # 源代码
│   ├── __init__.py
│   ├── data.py        # 数据处理
│   ├── model.py       # 模型定义
│   └── utils.py       # 工具函数
├── tests/             # 测试用例
├── requirements.txt   # 项目依赖
└── README.md          # 项目说明
```
