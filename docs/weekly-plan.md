# 从小白到 AI 专家：12 个月周计划

> 基于「基础 → ML → 深度学习 → 大模型应用 → 工程化 → 专家化」路线

## 第 3-4 个月：机器学习

### Week 7-8：机器学习基础

**学习内容**：
- 监督学习概念
- 线性回归
- 逻辑回归
- 训练集/测试集划分
- 模型评估指标（MSE、准确率、召回率）

**练习项目**：
- 房价预测（线性回归）
- 鸢尾花分类（逻辑回归）

### Week 9-10：特征工程

**学习内容**：
- 特征提取
- 特征缩放
- 类别编码
- 特征选择

**练习项目**：
- 用户流失预测
- 特征重要性分析

### Week 11-12：模型选择与调优

**学习内容**：
- 决策树
- 随机森林
- 交叉验证
- 网格搜索

**练习项目**：
- 文本分类（情感分析）
- 模型对比实验

### Week 13-14：完整 ML 项目

**项目**：端到端机器学习项目

1. 数据收集与探索
2. 数据清洗与预处理
3. 特征工程
4. 模型训练与对比
5. 超参数调优
6. 模型评估
7. 生成分析报告

## 第 5-6 个月：深度学习

### Week 15-16：PyTorch 基础

**学习内容**：
- Tensor 张量操作
- 自动微分
- Dataset 和 DataLoader
- 简单神经网络

**练习项目**：
- 手写数字识别（MNIST）

### Week 17-18：神经网络进阶

**学习内容**：
- 多层感知机
- 激活函数
- 损失函数
- 优化器

**练习项目**：
- 图片分类器

### Week 19-20：CNN 卷积神经网络

**学习内容**：
- 卷积层
- 池化层
- CNN 架构
- 迁移学习

**练习项目**：
- CIFAR-10 图片分类
- 使用预训练模型微调

### Week 21-22：RNN 与 Transformer

**学习内容**：
- 循环神经网络
- LSTM/GRU
- Attention 机制
- Transformer 基础

**练习项目**：
- 文本情感分析（LSTM）
- 简单翻译模型

### Week 23-24：训练调试技巧

**学习内容**：
- 学习率调度
- 正则化（Dropout、L2）
- 梯度裁剪
- TensorBoard 可视化

**练习项目**：
- 模型训练调试实战
- 过拟合与欠拟合处理

## 第 11-12 个月：垂直领域

### Week 41-44：垂直领域项目

**选择 1-2 个方向深耕**：
- 医疗 AI：病历分析、辅助诊断
